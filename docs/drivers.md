# Database drivers

> **Status:** PostgreSQL (Milestone 4) and MySQL (Milestone 15) implemented.

## Abstraction

```ts
interface DatabaseDriver {
  connect(): Promise<void>;
  disconnect(): Promise<void>;
  query<T>(sql: string, params?: unknown[]): Promise<QueryResult<T>>;
  transaction<T>(
    callback: (tx: TransactionContext) => Promise<T>,
  ): Promise<T>;
}
```

## Packages

| Package | Database | Priority |
|---------|----------|----------|
| `@zed-orm/driver-postgres` | PostgreSQL | First |
| `@zed-orm/driver-mysql` | MySQL 8+ | Second |

Core packages must not depend on `pg` or `mysql2`. Pooling uses mature driver capabilities; Zed manages lifecycle.

## PostgreSQL (`@zed-orm/driver-postgres`)

```ts
import { createPostgresDriver } from "@zed-orm/driver-postgres";

const driver = createPostgresDriver({
  databaseUrl: process.env.DATABASE_URL!,
});

await driver.connect();
const result = await driver.query("SELECT 1 AS value");
await driver.disconnect();
```

### Options

| Option | Description |
|--------|-------------|
| `databaseUrl` | PostgreSQL connection URL (required) |
| `max` | Pool size (default `10`) |
| `connectionTimeoutMillis` | Connection timeout |
| `idleTimeoutMillis` | Idle client timeout |

### SQL dialect

- Placeholders: `$1`, `$2`, …
- Identifiers: double-quoted (`"User"`)
- `RETURNING` on write operations

## MySQL (`@zed-orm/driver-mysql`)

```ts
import { createMysqlDriver } from "@zed-orm/driver-mysql";

const driver = createMysqlDriver({
  databaseUrl: process.env.DATABASE_URL!,
});

await driver.connect();
const result = await driver.query("SELECT 1 AS value");
await driver.disconnect();
```

### Options

| Option | Description |
|--------|-------------|
| `databaseUrl` | MySQL connection URL (required) |
| `connectionLimit` | Pool size (default `10`) |
| `connectTimeout` | Connection timeout in ms |

### SQL dialect differences

| Area | PostgreSQL | MySQL |
|------|------------|-------|
| Placeholders | `$1`, `$2` | `?` |
| Identifiers | `"name"` | `` `name` `` |
| Enums (migrations) | `CREATE TYPE … AS ENUM` | Inline `ENUM('A', 'B')` on columns |
| Auto-increment | `GENERATED BY DEFAULT AS IDENTITY` | `AUTO_INCREMENT` |
| UUID default | `gen_random_uuid()` | `UUID()` |
| DateTime | `TIMESTAMPTZ` | `DATETIME(3)` |
| JSON | `JSONB` | `JSON` |
| Bytes | `BYTEA` | `BLOB` |

Generated clients and `ModelDelegate` select the dialect from `datasource db { provider = "…" }` in `schema.zed`.

### Requirements

- MySQL 8.0+ (uses `RETURNING` on write operations, available since 8.0.21)
- Set `provider = "mysql"` in your schema datasource

## Errors

Driver failures throw `DriverError` with code `ZED_DRIVER_ERROR`. The underlying driver error is available on `error.cause`.

## Integration tests

| Variable | Driver |
|----------|--------|
| `DATABASE_URL` | PostgreSQL |
| `MYSQL_DATABASE_URL` | MySQL |

Tests are skipped when the corresponding variable is unset. Run `pnpm test` from the repo root.
